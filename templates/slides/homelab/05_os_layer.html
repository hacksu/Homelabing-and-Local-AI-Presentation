05 - OS LAYER

BARE METAL VS HYPERVISOR

Bare metal

Install Ubuntu or Debian and run things directly.

Simplest option, and it works on anything.

Hypervisor

Run many VMs and containers on one machine, with snapshots to undo mistakes.

Free (Proxmox), but needs more RAM and more to learn.

My lab: Proxmox, running 15 VMs (more on that in a few slides)
