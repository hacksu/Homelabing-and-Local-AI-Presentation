Slide 011:00

What is a homelab?

  • Any hardware at home you use to host services, learn, and experiment
  • Size doesn't matter: one laptop counts
  • Ask the room: who has run a Minecraft server? They've already homelabbed
Slide 023:00

Why should I have one?

  • Hands-on experience: things break and you learn by fixing them
  • Skills employers ask about: Linux, networking, containers
  • Own your data, and replace some subscriptions
Slide 035:00

My lab at a glance

  • Dell R740 for $460: 32 cores, 192 GB RAM, 10 TB
  • Point out what's in the photo; mention the router, switch, NAS, and UPS that aren't clearly visible
  • $1,549 total, built up over time, not all at once
Slide 049:00

Where can anybody start?

  • Free tier: whatever old machine you have
  • My story: OptiPlex from an office sale, then the R740 from Facebook Marketplace
  • Power: it runs 24/7, so an enterprise server costs real money on the electric bill
Slide 0512:00

Bare metal vs hypervisor

  • Bare metal: simplest, a good first step
  • Hypervisor: many VMs on one box, snapshots let you undo mistakes
  • Proxmox is free; the cost is RAM and learning time
Slide 0615:00

Networking and remote access

  • Static IP + DHCP reservation so the server's address never moves
  • Port forwarding: anything exposed gets scanned by bots within minutes; never expose SSH, RDP, SMB, databases, or Proxmox
  • Web is the usual exception, through one reverse proxy (my HAProxy)
  • Tailscale / WireGuard / Cloudflare Tunnel avoid forwarding at all
My lab: Tailscale exit node with Pi-hole DNS, so I get ad blocking on my phone anywhere.
Slide 0719:00

Extensions and add-ons

  • Storage: a NAS, or the server's RAID controller
  • RAID is not a backup: it doesn't save you from deleting a file or ransomware. 3-2-1 rule
  • UPS: rides out outages and gives time for a clean shutdown; Proxmox start/shutdown order decides what goes first
