06 - NETWORKING

NETWORKING AND REMOTE ACCESS

1. Static IP

Give your server a static IP and reserve it on your home router so its address never changes.

2. Port forwarding

Only forward what you have to, to a service you keep updated.

Never expose:

SSH 22 RDP 3389 SMB 445 DB 3306 / 5432 Proxmox 8006

Usual exception: web 80 / 443, through one reverse proxy.

3. Remote access

Skip port forwarding entirely with a tunnel or VPN:

Tailscale WireGuard Cloudflare Tunnel
My lab: Tailscale with an exit node whose DNS runs through Pi-hole, so I get ad blocking anywhere. HAProxy handles incoming HTTP for my web server.
